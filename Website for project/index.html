About the Architecture

Deep dive into the Smart Door Security Cloud & Streaming stack

System Overview

This web application operates as a standalone security monitoring hub. It enables direct real-time video streaming, instant high-resolution snapshot captures, and automated synchronization with Google Sheets as an encrypted, free cloud database.

Google Drive & Sheets Integration

When an alert occurs or a snapshot is taken, the frame is converted to Base64 and transmitted via HTTPS POST to your Google Apps Script Web App. The backend decodes the image, creates an image file in your private Google Drive folder, generates public embed links, and appends the visitor record row seamlessly.

Mobile & PC Native Experience

Engineered with responsive breakpoints, touch-friendly navigation docks for single-thumb mobile operation, tactile spring-physics animations, and Web Audio API synthesized sound effects.
